# Stock Analysis AI Web - クイックスタートガイド

## 🎯 概要

このプロジェクトは、AI を活用した株式分析のための Web インターフェースです。

## ✨ 主な機能

### 1. **美しい UI デザイン**
- ダークテーマとグラスモーフィズム効果
- アニメーション付きの背景
- レスポンシブデザイン（モバイル対応）

### 2. **チャットインターフェース**
- AI アシスタントとの対話
- メッセージ履歴の自動保存
- ローディングインジケーター
- エラーハンドリング

### 3. **サジェスション機能**
- よくある質問のクイックアクセス
- ワンクリックで質問を送信

## 🚀 使い方

### 開発モード

```bash
# 開発サーバーを起動（既に起動中）
pnpm run dev

# ブラウザで http://localhost:5173 を開く
```

### 質問の送信

1. 画面下部のテキストエリアに質問を入力
2. 「送信」ボタンをクリック、または Enter キーを押す
3. AI からの回答を待つ

### サジェスションの使用

初回表示時に表示される 3 つのサジェスションカードをクリックすると、すぐに質問を送信できます。

## 🔧 カスタマイズ

### API エンドポイントの変更

`src/config.ts` を編集：

```typescript
export const config = {
  development: {
    apiEndpoint: 'YOUR_API_ENDPOINT',
    useMockAPI: false, // 実際の API を使用する場合
  },
};
```

### デザインのカスタマイズ

`src/style.css` の CSS 変数を変更：

```css
:root {
  --color-primary: hsl(250, 100%, 65%);
  --color-secondary: hsl(280, 100%, 70%);
  /* その他の変数... */
}
```

## 📱 レスポンシブ対応

- デスクトップ: フル機能
- タブレット: 最適化されたレイアウト
- モバイル: タッチ操作に最適化

## 🎨 デザインの特徴

### カラーパレット
- **Primary**: 鮮やかな紫（`hsl(250, 100%, 65%)`）
- **Secondary**: マゼンタ（`hsl(280, 100%, 70%)`）
- **Accent**: シアン（`hsl(180, 100%, 60%)`）

### アニメーション
- メッセージのスライドイン
- ボタンのホバーエフェクト
- 背景のパルスアニメーション
- グラデーションのシフト

### グラスモーフィズム
- 半透明の背景
- ブラー効果
- 微細な境界線

## 🔌 API 統合

### モック API（開発用）

デフォルトでは、モック API が有効になっています。バックエンドなしでフロントエンドの開発が可能です。

### 実際の API との接続

1. `src/config.ts` で `useMockAPI: false` に設定
2. `apiEndpoint` を実際のエンドポイントに変更
3. API が以下の形式に対応していることを確認：

**リクエスト:**
```json
{
  "question": "株式に関する質問"
}
```

**レスポンス:**
```json
{
  "answer": "AI からの回答"
}
```

## 💾 データの永続化

チャット履歴は自動的にブラウザのローカルストレージに保存されます。

### 履歴のクリア

ブラウザのコンソールで以下を実行：

```javascript
localStorage.removeItem('chatHistory');
location.reload();
```

## 🛠️ トラブルシューティング

### TypeScript エラー

Alpine.js の型定義に関するエラーは、実行時には影響しません。開発を続けることができます。

### API 接続エラー

1. `src/config.ts` の設定を確認
2. API エンドポイントが正しいか確認
3. CORS 設定を確認（必要に応じて）

### スタイルが適用されない

1. ブラウザのキャッシュをクリア
2. 開発サーバーを再起動
